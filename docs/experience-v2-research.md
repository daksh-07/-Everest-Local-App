# Product and component research — 12 October 2026

Research informs the shipped intent controls, deferred data loading, retained navigation and useful Search states. It does not authorize copying product layouts, assets, proprietary interaction code or fabricated marketplace content.

## Observation limits

Public pages were opened in Chromium with a 390 × 844 touch viewport and captured under `/workspace/scratch/everest-qa/references`. Uber exposed its location entry and documented matching sequence. Instagram exposed authentication. Linear and Shopify exposed workflow documentation. Google Maps exposed its signed-out map/search surface. Airbnb returned its navigation shell without listing content in this environment. Pinterest returned a sparse shell; Etsy returned 403; Booking.com returned a challenge response. Their accessible help/product documentation supplements research. WhatsApp's public site is product guidance, not an authenticated chat client. Apple's linked Maps URL resolved to the iPhone guide landing page, so it is not proof of a tested Maps interaction.

No native or authenticated competitor experience was tested. Loading/keyboard/motion claims for those experiences are design hypotheses to validate, not measured facts. Sources were read, not imported as designs.

## Reusable implementation candidates

README, actual LICENSE files and relevant source were fetched from each repository's HEAD. Compatibility is evaluated against Everest's **pinned** Expo 54 / RN 0.81.5 / Reanimated 4.1.1 / React 19.1 / Web 0.21, not assumed from permissive peer ranges. All five repositories' retrieved licenses are MIT: commercial use is permitted subject to retaining copyright/license notices in copied substantial code. No upstream code was copied and no dependencies were added.

| Candidate | Source inspected / compatibility and cost | Decision |
| --- | --- | --- |
| [shadcn/ui](https://github.com/shadcn-ui/ui) | `apps/v4/registry/new-york-v4/ui/button.tsx`: variants, focus, disabled behavior; DOM/Radix/Tailwind implementation is not native RN | Adapt principles of distinct action variants; use existing RN components, not a web styling migration |
| [React Native Reusables](https://github.com/founded-labs/react-native-reusables) | `packages/registry/src/nativewind/components/ui/button.tsx`: RN Pressable, text context, platform focus variants; NativeWind/class utilities add styling infrastructure; latest examples also have a Uniwind path | Keep StyleSheet/theme architecture; 44 px minimum and explicit focus/selection are useful, library's smaller sizes are not adopted |
| [Reanimated](https://github.com/software-mansion/react-native-reanimated) | `packages/react-native-reanimated/src/animation/spring.ts` and package metadata; current installed 4.1.1 already matches Expo 54 and RN 0.81 | Preserve UI-thread transforms/shared progress. | [FlashList](https://github.com/Shopify/flash-list) | `src/FlashListProps.ts`, `src/recyclerview/RecyclerView.tsx`, README/package metadata: v2 requires New Architecture, which Everest enables; recycling changes row-state semantics; web/native need separate measurements | Defer installation until profiling proves a list bottleneck. ## Platform guidance used

- [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/): readable hierarchy, standard interaction expectations and sufficient touch areas.
- [Material navigation](https://m3.material.io/components/navigation-bar/overview): consistently labeled primary destinations and selected state.
- [Expo SDK 54 Reanimated](https://docs.expo.dev/versions/v54.0.0/sdk/reanimated/): preserve the supported installed version and Worklets relationship.
- [Reanimated performance](https://docs.swmansion.com/react-native-reanimated/docs/guides/performance/): New Architecture performance issues can involve commit scheduling, gesture hit testing and layout work. Prefer transform/opacity; measure native hardware before changing static feature flags or claiming 60 fps. This release does not enable unmeasured flags.
- [Supabase abortSignal](https://supabase.com/docs/reference/javascript/db-abortsignal): cancel superseded search transport in addition to invalidating stale responses.

## Design foundation

Retain `lib/theme.tsx` as color/token authority and `lib/experience.tsx` as appearance-mode authority. New category UI consumes existing tokens; it does not create another palette. Warm ivory/charcoal/champagne remain identity, green remains semantic. DEFAULT/PULSE/CLASSIC preserve user preferences, label readability, touch sizes and reduced-motion behavior. Search uses 16 px inputs, 16 px result titles, 14 px supporting content, 20 px section titles and 28 px screen title. Expressive fonts are not introduced: current main has no Fraunces font loading in these surfaces. A cross-native typography change needs actual iOS/Android rendering evidence before adoption.
