# Country-aware business discovery — 30 October 2026

## Implemented decisions

- Home keeps country in its discovery key and applies a literal, case-insensitive country filter before each local query and candidate limit. Broader fallback remains within that country. Empty country supply never silently falls back to Australian or global businesses.
- Only active verified business listings are returned. Listing location is not a promise that a provider serves an address; local/country-wide scope and service-area checks remain explicit.
- See all retains country. The Businesses tab now opens its directory without requiring a keyword; blank People searches remain disabled. Scoped business-name search uses existing PostgREST/RLS and applies country before pagination.
- Search all areas is a deliberate opt-out. Other search types are explicitly labelled All areas when country context exists; services/products have not gained an unreviewed country or shipping promise.
- Recent business searches retain their country in device history and show it to the user. Legacy unscoped history remains readable. Country-scoped saved alerts are disabled with an explanation because the current server matcher does not enforce country; the existing all-area saving action remains available after opting out.
- Available now carries the chosen country/locality, offers manual location recovery without a permission prompt, preserves the resolved country in its browse fallback, and distinguishes failed reads from empty supply with a retry action. Superseded reads are ignored. A joined public read applies country, locality, verification, active status, accepting-requests, explicit AVAILABLE_NOW and expiry predicates before its candidate limit. It does not silently choose a country after denial/missing profile country.
- Profiles explicitly marked not taking requests (or known inactive/unverified) do not display actionable quote/instant-booking controls. Enquiry and catalogue viewing remain available. Authoritative booking/payment checks stay on the server.
- Home search no longer promises an unimplemented local search scope. Product discovery is explicitly across Everest, prices remain AUD, and fulfilment coverage must be checked. No currency is guessed from the chosen country.

Alternatives rejected: filtering a global page after pagination (misses valid providers and produces false empty results); silently broadening country (wrong providers); treating business headquarters as proof of service-area eligibility; relabelling AUD values as INR/CAD; enabling scoped alerts that the server does not honour. No new paid service, database mutation, permission grant, migration or financial-policy change is included.

These require coordinated server contracts, review and isolated acceptance. Business-directory filtering by the stored country name is not worldwide checkout readiness.
