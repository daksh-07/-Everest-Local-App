# Experiment backlog — untested hypotheses

No experiments were launched, traffic retrieved, winners declared or analytics service added. Bug/accessibility fixes are not A/B tests. Actual baseline traffic and conversion are unknown. Research references are in the evidence register.

## Common protocol

Before launch: define the eligible population and baseline completion rate, minimum detectable effect, 80% power and two-sided 5% alpha; calculate sample size for the selected metric with independent randomization units. Duration = required eligible units / measured traffic, covering weekly patterns. No numeric sample size is defensible without those inputs. Use stable user assignment (anonymous session until consent/account), exclude staff/test traffic, no reassignment mid-flow, one conflicting journey experiment at a time. Count exposure only when the alternative renders. Missing/duplicate events invalidate analysis.

Use allowlisted event names and coarse properties: variant, journey step, success/error category, platform, duration bucket. Never send query text, precise location, freeform descriptions, names, email, messages, credentials or financial contents. No telemetry collection is implemented by this document. Define consent, retention and access before instrumentation. Use server-confirmed completion events rather than redirect visits for transactions.
